# Business model

AdaptiveSurgeon is not a single product but a platform with multiple revenue
streams layered on a shared data + intelligence core.

## Revenue streams

| Stream | Buyer | Indicative pricing |
|--------|-------|--------------------|
| **Analytics platform** | Hospital departments | ₹5–20 lakh / year per dept |
| **Surgical Copilot** | Per operating room | ₹3–10 lakh / year per OR |
| **Hardware appliance** | Per OR (AI box) | ₹1–15 lakh per OR |
| **Digital Twin** | Per case | ₹5,000–₹50,000 by complexity |
| **Training platform** | Medical colleges | subscription / seat |
| **Foundation-model API** | Hospitals / partners | usage-based query API |

## Why this compounds

The product is a **Surgery Data Network + Hospital Integrations + Outcome
Database + Foundation Model**, not just an AI model. Each surgery improves the
dataset; each hospital integration deepens distribution; each outcome enriches
the knowledge base. These assets compound and are not easily copied — the moat
is the network and the data, not the segmentation weights.

## Go-to-market wedge

Start with the **Analytics + Skill** platform for teaching hospitals (objective,
measurable assessment where today's evaluation is subjective), then expand into
the real-time **Copilot** and **Digital Twin**, and finally the
**Foundation-model API** as the dataset matures.
